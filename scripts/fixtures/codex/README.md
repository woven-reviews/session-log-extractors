# Codex fixture provenance

These seven native fixtures cover the captured shapes recorded in [QUAL-2400](https://linear.app/andela/issue/QUAL-2400/codex-test-coverage). Captured on 2026-10-15 with Codex CLI 0.162.1. There are **no hand-authored JSONL fixtures**. Tests read committed files and require no local Codex login or session directory.

## Regenerate

Run `python3 scripts/generate_codex_fixtures.py` from the repository root with a logged-in `codex` CLI for the headless captures, then `python3 scripts/generate_codex_fixtures.py --interactive` for Plan mode, answered question, and declined permission captures. Both commands make model calls. Each case runs in a temporary workspace. The headless cases use `codex exec --json --ignore-user-config`; the interactive cases use the `codex app-server` protocol and read its saved native rollout JSONL, not its JSON-RPC notification stream. The model case resumes its first thread under `gpt-6-luna`. The image case attaches `pixel.png`, a 64×64 synthetic test asset enlarged from a one-pixel source; the 1×1 source was too small for this Codex CLI to process. The script finds only the new thread IDs, retains relevant native records, strips startup and mode instructions and unrelated tool output, redacts home/workspace paths, checks each capture's shape, and stages all outputs before replacement. Session IDs and timestamps vary on regeneration. Review the diff before committing.

| 4. `request_user_input` answer | **App-server capture:** `question.jsonl` records the native options request and the answered result. |
| 5. Pasted images | **Headless-generatable:** `image.jsonl` contains a native base64 `input_image` block and image path; tests decode it using committed `pixel.png`. **Fixture-only:** a deleted backing file requires deliberate mutation; the missing-path test stays inline. |
| 6. `apply_patch` changes | **Headless-generatable:** `tool_patch_large.jsonl` contains the native `FileChange` and `custom_tool_call` records. | 9. Malformed JSONL | **Fixture-only:** a completed headless run cannot intentionally end with a truncated line. The loader test keeps its small inline partial line. |
